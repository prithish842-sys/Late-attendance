# Weekly Audit Workflow

At week end:
1. Aggregate by department.
2. Count unique late students and total late events.
3. Identify repeated-late students.
4. Sort departments by actual count.
5. Show `Weekly Audit` suggestion.
6. PT Sir selects department(s).
7. Generate weekly department PDF and formal email.
8. Preview.
9. Send after confirmation.
10. Save mail result.

Repeated-student view:
- name
- register number
- department
- year
- weekly late count
- current-month late count
- last late date

Audit history shows week, department, recipient, timestamp, status and attachment.
