# New UI/UX Design

## PT Sir dashboard
- live date/time at top
- large attractive `Scan Student` card with scan icon
- today's count
- today's scanned-student list
- repeated-late alerts
- weekly audit suggestion

## Scanner
Camera scanner first; manual Register Number container directly below it.

## Verification
Photo -> Name -> Register No -> Department -> Year -> current-month status -> `Scan Next Student` / `Submit`.

## Reports
Department + year + date-range filters, preview, PDF, Excel, HOD send.

## HOD mail preview
Show To, Subject, formal body, period, department, year-wise list and attachment names before final send.

Year order: 3rd Year -> 2nd Year -> 1st Year.

## Audit
Department, unique students, total events, repeated students, mail status, week filter/search.

## Admin
Student Management, Batch Import, Archive/Delete, Recently Deleted, Restore/Permanent Delete, Department/HOD.

Keep mobile-first layout, large touch targets, simple wording, clear success/error states and explicit destructive-action confirmation.

## Design principles
See `NEW_DESIGN_PRINCIPLES.md` for the specific UI/UX laws (60-30-10 color rule,
Hick's Law, Fitts's Law, Jacob's Law, Miller's Law, Peak-End Rule, Von Restorff
Effect) that must be applied to every screen above, and how each one maps to a
concrete PT Sir/Admin workflow problem.
