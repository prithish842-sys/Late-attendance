Start with `docs/NEW_UPDATES_PRD.md`, then `docs/NEW_WORKFLOW.md`.

Also see `docs/NEW_DESIGN_PRINCIPLES.md` (UI/UX laws applied per screen) and

(PT Sir, Admin — no HOD login) and clarifies what "remove Firebase
